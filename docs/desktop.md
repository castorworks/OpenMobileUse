# 桌面工作台

工作台默认自动启动或复用独立运行的本机 `omu serve`，并为自己配置访问令牌。macOS 可双击 `Open Mobile Use.app`，Windows 和 macOS 都可从仓库根目录运行 `npm run desktop`。退出工作台后，服务和已受理的运行会继续工作。再次打开工作台可查看历史，或继续观察进行中的运行。 [安装与设备接入](setup.md)

## 开始使用

1. 将已解锁的手机连接到服务宿主，并在手机上完成调试或信任授权。只有一台可用设备时，工作台会自动选中它。使用本机服务的 macOS 工作台也可启动 Android 模拟器。
2. 在左侧选「对话」，输入目标。Enter 发送，Shift + Enter 换行。右侧显示手机画面。「执行过程」显示进度和结果，可在原对话回复追问，也可在运行时点「停止」。
3. 左侧选「脚本」打开脚本库，导入 JSON 或运行已保存的脚本。

工作台连不上服务时，在设置中点「诊断服务连接」，检查 HTTP 服务、运行受理状态和访问令牌。已发现的设备连不上时，点右栏「连接诊断」查看失败环节。设备存在待核对动作时，先刷新画面，再在连接诊断中对照手机确认当前状态。停止运行会停止后续调度，系统仍会等待已派发动作的回执。

## 工作台设置

- **服务连接**。默认自动配置本机服务。连接其他服务时选择自定义服务，输入地址和访问令牌。远程服务使用 HTTPS。也可用 `OMU_API_URL` 和 `OMU_API_TOKEN` 指定连接。工作台通过系统凭据存储保存令牌。
- **模型配置**。选择服务提供的模型。本机自动启动会沿用宿主或原工作台已有的模型配置。没有已有配置时，服务也可使用本机 Ollama 中已安装且支持工具调用的模型。 [模型配置](cli.md#agent-自主导航)
- **截图**。「允许模型按需查看手机截图」默认关闭。开启后，服务可以按需将画面发给所选模型，需要该模型配置允许接收图片。
- **本机平台工具**。使用本机服务时，可查看平台工具、准备 Android 环境或选择 SDK 位置。远程服务的 SDK、HDC、Xcode 和 iPhone 签名需要在设备宿主配置。 [设备接入](setup.md#设备接入)

## 对话和单步操作

服务会把任务、前台应用和可见控件摘要发给配置的模型。服务宿主可在本机识别画面文字，内置简体中文、繁体中文和英语数据。macOS 在 Apple Vision 可用时优先使用它。开启截图并选择支持图像输入的模型后，对话还可以通过画面定位自绘界面的文字和图标。

对话支持点击、滑动、返回、启动应用、输入普通字段，以及边浏览边汇总内容。在安卓上说「退出到桌面」，服务会执行系统 Home 并核对默认主屏幕。窗口切换或定位目标发生变化时，服务会先重新观察。遇到敏感画面或系统对话框时，请按运行提示在手机上处理。

在抖音关闭评论时，服务会在按钮内选取避开系统手势区的位置，点击一次，再核对面板和原作品。明确要求只上滑一次并核对是否换片时，服务只下发一次上滑，以前后读到的作者或标题报告结果。证据不足或回执丢失时，工作台显示待核对。

右栏「单步操作」支持通过稳定画面点击、滑动、返回和输入。在安卓动态画面上，服务可以在点击或滑动前单独核对目标区域。旧预览上的点击目标发生变化时，工作台取消该次点击并刷新画面。勾选「将手动操作加入当前对话的录制」，可把已确认的手动动作加入选中的对话。

### 录制

服务会保存对话和已确认的步骤。每份录制最多保存 1000 步，可包含输入到普通输入框中的内容。选择「新对话」可单独记录下一个任务。完成后点击「保存录制到脚本库」，从当前对话的已确认步骤创建可单独编辑和管理的脚本副本。

从旧版工作台切换时，可把已有的脚本 JSON 导入服务。旧版保存在本机的对话文件会保留在原目录。通过服务创建的新对话可在工作台切换设备后查看。

要续录旧脚本，在脚本库导入原录制，选中同平台设备，在「管理」中点「续录为新对话」。服务会复制已录制的步骤，后续确认的操作追加到新对话，原录制可继续导出和重放。

## 脚本库

脚本库显示服务的内置脚本、导入的 JSON 和保存的录制副本。可搜索、导入、导出脚本，在「管理」中重命名或归档自己的脚本。勾选「显示已归档的脚本」并打开管理菜单，可恢复已归档脚本。

恢复任务所需的起始界面，在兼容设备上点「运行」即可由服务直接重放。前台应用、控件或读数不匹配时会停在对应步骤。

- 通过截图定位的步骤会重新查找画面中的目标。目标消失或无法唯一区分时会停下。
- 按画面文字录制的步骤会在重放时用宿主本机识别重新查找目标文字。Windows 和 macOS 可共用这类录制。两端的识别结果可能有差异，文字缺失或重复时会停在对应步骤。
- 录制用于相同手机平台上的兼容设备。iPhone 录制需要连接设备的 macOS 宿主。
- 工作台、CLI 与 HTTP API 共用脚本 JSON。已有的 V2 录制可直接导入或重放，导出时使用统一的平铺格式。服务支持根据所属卡片区分重复的安卓控件，并可重放已录制的暂停视频、返回主屏幕和核对搜索结果等步骤。 [脚本格式](cli.md#脚本和条件等待)
