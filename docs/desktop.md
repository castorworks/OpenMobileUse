# 桌面工作台

按 [安装与设备接入](setup.md) 准备后，在 macOS 上双击 `Open Mobile Use.app`，或在仓库根目录运行 `npm run desktop`。Windows 使用 `npm run desktop` 启动。

## 开始使用

1. 连接已解锁的手机并完成 USB 授权。只有一台可用设备时，工作台会自动选中它。macOS 上也可以点「启动 Android 模拟器」，让工作台准备镜像、创建并启动专用模拟器。
2. 首次需要云模型时，在「工作台设置」填写 API Key，见下文。
3. 在左侧选「对话」，在中间输入目标，例如「打开设置，找到蓝牙，告诉我当前开关状态」，按 Enter 发送，Shift + Enter 换行。右侧显示手机画面，每条消息下方实时显示执行过程。结束后步骤自动收起，点击「执行过程」可按时间顺序回看。遇到追问可在原对话回复，运行时可在输入框旁点「停止」。
4. 左侧选「脚本」打开脚本库，重放录制的操作，见下文。

设备连不上时，点右栏「连接诊断」查看失败的环节和处理提示。

## 工作台设置

- **模型**：默认端点使用 DeepSeek，也可以填写支持工具调用的 Chat Completions 地址和模型名。地址需使用 HTTPS，本机回环地址可用 HTTP。启动时若没有配置云模型，工作台会尝试发现本机 Ollama 已安装、支持工具调用的模型。
- **API Key**：由操作系统的凭据存储加密保存，免鉴权的本机模型可留空。
- **截图**：「允许模型按需查看手机截图」默认关闭，用法见下文的识图。
- **设备环境与 iPhone 签名**：查看平台工具的检测结果，准备 Android 工具或选择 SDK 位置，获取 DevEco Studio 或 Xcode，在 macOS 上选择 Apple Team ID 和 WDA Bundle ID。

## 对话

对话会向选定模型发送任务、前台应用和可见控件摘要，截图发送默认关闭。Windows 和 macOS 都可以在本机识别画面文字，把文字和位置提供给模型。本机识别内置简体中文、繁体中文和英语数据，macOS 优先使用 Apple Vision。

对话支持点击、滑动、返回、打开应用或在普通输入框内输入文字，也可以让模型边滑动浏览边记录，最后汇总。密码或系统弹窗需要在设备上处理。

窗口切换、控件暂时不可用或输入前焦点变化时，对话会重新读取界面，再决定下一步。如果截图期间前台窗口发生变化，工作台会丢弃该帧，重新读取窗口和截图。截图持续不可用时，会改用当前的原生控件。

启动命令已发出、目标应用还没出现在前台时，对话会检查当前页面，可以通过可见入口继续。模型偶尔返回截断或格式有误的操作指令时，工作台会重新观察并请求下一步，最多连续重试两次。

文字已发出但输入框暂时读不到时，对话会重新观察。它可以选择眼前的搜索建议或结果继续任务，同一轮会避免向原输入框重复发送相同文字。录制只保存核实过的操作，如果一次输入始终没有核实，重放时可能需要手动恢复那一步的页面状态。设备丢失操作回执时，工作台仍会暂停供你核对。

工作台会自行选择符合目标的入口。连续两次无法在同一画面定位点击目标时，它会尝试可见控件、画面文字或滑动等其他路径。一轮对话最多执行 1000 次决策、10 分钟。多次尝试仍无法完成时，会汇总已读内容并说明卡点。如果需要你辨明目标或在手机上解锁，它会在原对话中提出具体请求。

### 识图

要让模型直接看游戏画面，在「工作台设置」选择支持图像输入和工具调用的模型（例如 DeepSeek 官方的 `deepseek-flash`），勾选「允许模型按需查看手机截图」并保存。Windows 和 Mac 都支持。开启后，工作台在原生控件不够用或模型请求时，把当前截图发往配置的接口。你可以说「开始一局游戏」，模型可以通过截图定位按钮文字或图标，再查看操作结果。

对于有点击区域但没有名称的工具栏图标，工作台可以结合原生控件的中心和截图校准落点。视频背景使图标轮廓暂时看不清时，工作台会再取一帧，在原位置附近确认图标后点击。

### 录制

对话中的操作会自动录制成脚本。对话记录和录制脚本保存在本机 `~/.openmobileuse/conversations/`，包含普通输入框的录制内容。每份录制最多保存 1000 步。右侧「单步操作」可以手动点击、滑动、返回和输入，需要把手动操作也加入脚本时，勾选「将手动操作加入当前对话的录制」。选择「新对话」即可单独录制下一个任务。

## 脚本库

脚本库集中显示内置脚本、各设备的对话录制和导入的 JSON。可以搜索、导入、导出脚本，在「管理」里重命名或移除自己的脚本。移除的对话录制可以在原对话中点「恢复到脚本库」找回。

恢复任务所需的起始界面，在兼容设备上点「运行」即可离线重放。前台应用、控件或读数不匹配时会停在对应步骤。

- 通过截图定位的步骤，重放时会在画面上重新查找录制时的目标。对于多个外观相同的按钮，工作台可以用同一行的栏目标题等图像特征区分，并在点击前再次核对按钮。工作台也可以按轮廓核对视频上的图标。目标消失或无法唯一区分时会停下。含同行特征或轮廓匹配的录制需要在支持相应功能的工作台版本上重放，已有录制仍按原方式匹配。
- 按画面文字录制的步骤会在重放时用本机识别重新查找目标文字。Windows 和 macOS 可共用这类录制。两端的识别结果可能有差异，文字缺失或重复时会停在对应步骤。
- 录制只能在与录制时相同平台的手机上重放，iPhone 录制只能在 Mac 上重放。
- 工作台和 CLI 共用一种脚本格式，可以直接交换录制文件。 [脚本格式](cli.md#脚本和条件等待)

早期开发版的录制需要重新录制。旧对话仍可查阅。
